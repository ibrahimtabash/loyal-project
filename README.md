# رِجعة — Laravel + React monolith

تطبيق Laravel 12 وReact 19 مرتبط عبر Inertia 2، مع واجهة متجر عربية جديدة بالكامل، لوحة تاجر وإتمام الطلب عبر واتساب.

## المعاينة المحلية

- الرئيسية: http://127.0.0.1:8000
- متجر التصميم التجريبي: http://127.0.0.1:8000/s/dar
- أنشئ حسابك ومتجرك: http://127.0.0.1:8000/register

```sh
composer install
npm ci
# في التشغيل الأول فقط: انسخ .env.example إلى .env ثم ولّد APP_KEY
php artisan key:generate
php artisan migrate
php artisan db:seed --class=DemoStoreSeeder
npm run build
php artisan serve
```

إذا كانت البيئة مهيأة، لا تُعِد إنشاء `.env` أو `APP_KEY`. للتطوير: `php artisan serve` و`npm run dev` في نافذتين. في هذا الجهاز PHP موجود في `D:\xampp\php\php.exe`.

## ما يعمل الآن

- تسجيل وإنشاء متجر خاص بكل تاجر، ودخول بجلسات Laravel.
- واجهة متجر RTL بتصنيفات وبحث وترتيب ومفضلة وتفاصيل منتجات.
- سلة محفوظة لكل متجر، وتوصيل أو استلام، وحساب الأسعار في الخادم.
- حفظ الطلب وتفاصيله معاً، ثم رسالة واتساب جاهزة يرسلها العميل بنفسه.
- لوحة إحصاءات، إضافة وتعديل المنتجات، رفع الصور، إعداد المتجر ونشره، متابعة حالات الطلبات.
- ملفات عملاء وملاحظات خاصة، ومحافظ نقاط بسجل لكل حركة، وربط تلقائي بالطلبات المؤكدة.
- منح النقاط عند التسليم مرة واحدة، واستبدال المكافآت مع منع الرصيد السالب وتكرار الخصم.
- إدارة المكافآت وكمياتها وصورها، وعرض المتاح منها في المتجر.
- اختبارات لعزل المتاجر، الأسعار، تكرار الطلب، الصلاحيات والملفات.

## نطاق النقل

النسخة الجديدة تستخدم قاعدة Laravel مستقلة ولا تتصل بـSupabase. بقي الكود القديم كمرجع في `src` و`supabase`، وإعدادات البناء الأصلية في `legacy`. أُضيفت ملفات العملاء ومحافظ النقاط والمكافآت في Laravel، لكن بيانات وحسابات الإنتاج لم تُنقل، ولم يتم النشر الخارجي. الفواتير والاشتراكات وحملات واتساب القديمة ما زالت خارج النسخة الجديدة.

عند ترقية نسخة Laravel السابقة نفّذ `php artisan migrate` ثم `php artisan loyalty:sync-orders` لربط الطلبات السابقة بسجل النقاط. الأمر قابل لإعادة التشغيل دون تكرار منح نقاط الطلبات. الاستبدال من لوحة التاجر بعد التحقق من العميل وتسليم المكافأة؛ لا يوجد استعلام عام عن الرصيد برقم الهاتف.

متجر دار وصوره بيانات عرض فقط؛ لا يوجد حساب بكلمة مرور مشتركة، ولا رقم واتساب حقيقي. أنشئ حسابك للتجربة الكاملة.
